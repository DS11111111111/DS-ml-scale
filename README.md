# Воспроизведение и улучшение XGBoost и LightGBM

## Описание проекта

Воспроизведение результатов оригинальных статей XGBoost и LightGBM, а также разработка ансамблевых методов (простое усреднение, взвешенное усреднение, Stacking) для повышения точности предсказаний.

**Датасет:** California Housing (20 640 объектов, 8 признаков)

## Результаты

| Модель | RMSE | R² |
|--------|------|-----|
| Stacking (Ridge) | **0.4359** | **0.8550** |
| Simple Averaging | 0.4362 | 0.8548 |
| Weighted Averaging | 0.4370 | 0.8543 |
| XGBoost (статья) | 0.4424 | 0.8507 |
| LightGBM+GOSS | 0.4541 | 0.8427 |

**Лучший результат:** Stacking (Ridge)  
**Улучшение относительно baseline:** +16.2%
